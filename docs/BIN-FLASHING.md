# Syna v1.0.0-rc.2 独立 BIN 刷写

仅适用于微雪 ESP32-S3-RLCD-4.2：ESP32-S3，16 MB Flash、8 MB PSRAM。

## 首次安装 / 替换其他固件
文件：Syna-1.0.0-rc.2-full-16MB.bin（16 MB）
写入地址：0x0
包含 bootloader、分区表、OTA 初始化数据、应用及屏幕资源。
完整镜像会覆盖全部 Flash，清除 Wi-Fi、电脑绑定及其他设备配置。先备份，刷写期间不要拔线。

使用 esptool 5.4.0 的示例（COM9 替换为自己的开发板串口）：
python -m esptool --chip esp32s3 --port COM9 --baud 921600 --after hard-reset write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB 0x0 Syna-1.0.0-rc.2-full-16MB.bin

其他刷写工具选择 ESP32-S3、DIO、80 MHz、16 MB，将完整 BIN 放在地址 0x0。

## 应用镜像（高级用途）
文件：Syna-1.0.0-rc.2-app.bin
这是单独的应用，不包含启动程序、分区和资源，不能写入 0x0，不能用于空白设备首次安装。
构建默认应用地址为 0x20000；已有设备可能从另一 OTA 分区启动，不能直接假定该地址。
仅在确认设备分区、当前启动槽、资源兼容性，并自行处理 OTA 启动选择时使用。保留配置升级优先使用图形安装器。

## 验证与启动
BIN 来自 rc.2 安装器同一批固件。已验证应用哈希、完整镜像五段内容及填充区域。应用 BIN 保留配置升级与完整 BIN 首次安装均已在作者设备实测成功，完整镜像 16 MB 读回与发布文件一致。
刷写工具显示完成后等待启动；若屏幕未亮，再重新插拔并按开机键。Wi-Fi 和电脑绑定需重新配置。
BIN-SHA256SUMS.txt 为这些独立 BIN 和本说明的校验值。不会安装电脑端 Reporter；需要电脑数据时另行安装。
## 小智语音配置

1. 开发板首次启动后，按屏幕提示连接设备热点，打开提示的配网页，设置可用的 Wi-Fi。电脑绑定与 Wi-Fi 设置按设备页面完成。
2. 浏览器打开 https://xiaozhi.me/，登录并进入“控制台”。
3. 如果设备显示或播报激活码，在控制台按提示添加设备，输入当前激活码，绑定到自己的账号或智能体。已绑定的设备先在原账号下查找；清空 Flash 不一定解除云端绑定。
4. 在设备关联的智能体中进入“配置角色”，设置角色人设、音色，以及页面提供的模型等选项，保存后重新唤醒测试；未生效时重启设备。
5. 小智控制台用于语音对话配置；电脑性能、Agent 和音乐数据显示需要电脑端 Reporter，另在开发板上选择电脑。

没有激活码时，先确认设备已经联网。已能正常对话的设备通常无需重新激活；控制台入口名称以网页实际显示为准。
