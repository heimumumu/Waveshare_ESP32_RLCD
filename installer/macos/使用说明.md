# 希娜 Syna · Mac 安装包 v1.0.0

作者：黑沐 · B站 UID 386856267 · QQ 3091479711

适用硬件：微雪 ESP32-S3-RLCD-4.2（16 MB Flash）。
Mac：Apple 芯片，最低系统声明为 macOS 13；当前实测为本机 macOS 26。
Intel Mac 尚未包含在此安装包中。安装无需 Python、ESP-IDF 或管理员密码。

## 使用

1. 打开 DMG，双击 **SynaInstaller.app**。
2. 使用支持数据传输的 USB 线连接开发板，点击“刷新设备”。
3. 已使用本项目固件时选择“保留配置升级”；新板或替换其他固件选择“首次安装”，阅读并勾选清除数据确认。也可以仅安装 Reporter。
4. 点击“一键安装”，等待备份、校验、刷写和 Reporter 安装完成。期间不要拔线或关闭电脑。
5. Reporter 会自动打开。让电脑和开发板接入同一个可互访的 Wi-Fi，按开发板提示完成配网并选择电脑。

无法连接串口时：按住 BOOT 重新插入 USB，再松开 BOOT，然后重试。
PWR 为短按开机、长按关机；装入电池后可能需要接一次 USB 激活。
关闭 Reporter 窗口不会退出服务；Command+Q 会退出。登录自启动可在 Reporter 窗口调整。
系统询问本地网络、音乐自动化等权限时，按所需功能允许。

## 备份和升级

- Reporter 安装到 `~/Applications/SynaReporter.app`，电脑端设置保留在原有 Application Support 目录。
- 升级已有应用时，旧 Reporter 会移到本次备份目录。安装期间会正常退出已运行的 Reporter。
- 设备完整 Flash 在写入前读取并校验；失败时不会继续刷写。
- 备份与日志：`~/Library/Application Support/SynaInstaller/Backups/`，安装器中可直接打开。
- **设备备份包含 Wi-Fi、激活等私有配置，不要上传或公开分享。**
- 保留配置模式要求分区布局与本型号兼容，并识别现有板型和启动分区；不兼容时会拒绝写入。
- 首次安装会清除开发板数据，但先保存并校验原始完整备份。
- 安装失败可查看日志并重试；如果刷写已经完成而 Reporter 安装失败，可改选“仅安装 Reporter”。
